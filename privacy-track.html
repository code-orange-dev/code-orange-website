Review is a contribution. Usefulness is the rule.

The biweekly Privacy Review Club works from real upstream PRs. Participants build the branch, run tests, read the relevant code and history, discuss trade-offs, and only then provide feedback when it is genuinely useful.

✓ The track is for you if
→ You're comfortable in at least one programming language (Rust helps, not required) → You have Bitcoin foundations already, or can demonstrate them in an assessment → You want to become useful to an upstream project, not collect a certificate → You can learn independently, respond to feedback, and sustain real project work
✕ It's not for you if
→ You're brand new to programming - do rawBit first → You only want a guaranteed PR count or a fast credential → You are not ready to test, review, communicate, and improve alongside others
